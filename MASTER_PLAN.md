# Master Plan

## Scope

The project audits whether virtual perturbation models recover perturbation-specific biology under increasingly strict evaluation. The first execution target stops at the Norman + GEARS + baselines pilot.

## Phase Order

P0 provenance -> P1 dataset QC -> P2 baseline -> P3 split integrity -> P4 GEARS pilot -> P5 truthfulness -> P6 hallucination -> P7 Replogle -> P8 scGPT/scFoundation -> P9 STATE -> P10 temporal-clean -> P11 figures -> P12 manuscript.

## Pilot Deliverables

- Norman acquisition and provenance card
- Norman QC
- L0 random-cell, L1 perturbation-held-out, L2 component-held-out splits
- Split integrity tests
- No-change, global mean, context mean, PCA/Ridge baselines
- GEARS official reproduction attempt
- Pearson-delta, perturbation retrieval, BNS, UER@50, Sign Flip Rate
- Pilot decision report
