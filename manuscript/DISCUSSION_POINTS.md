# Discussion Points

- Prediction similarity is not the same as perturbation-specific mechanistic generalization.
- Benchmark overlap and pretraining contamination should be separated from ordinary legal pretraining and from evaluation leakage.
- Systematic variation can inflate global transcriptomic metrics.
- Simple baselines define empirical lower bounds and prevent overinterpreting complex models.
- Biological hallucination should be defined against replicate-derived null envelopes, not by equating nonsignificance with falsehood.
- Transcriptomic ground truth has measurement limits; null evidence is not proof of absence.
- Foundation model provenance requires explicit corpus and cutoff evidence.
- Temporal-clean analyses should be described as evidence-based clean candidates unless exact corpus exclusion is documented.
- The project is an audit framework, not a leaderboard.
