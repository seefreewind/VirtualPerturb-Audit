# STATE Adapter Audit

The Phase 2C adapter maps frozen GEARS perturbation conditions into STATE-compatible AnnData/TOML inputs without changing split membership.

- control label: `ctrl`
- perturbation label mapping: trailing `+ctrl` is removed for STATE `gene`; raw GEARS condition is retained in `obs.condition`.
- cell type fields: Norman `A549`, Replogle `K562` or `RPE1`.
- batch/context field: `gem_group`, set to the locked Phase 2C dataset key.
- split source: frozen GEARS pickle files only.
- BNS status: UNVERIFIED; not used as a primary endpoint.
